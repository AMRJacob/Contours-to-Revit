    One-click updates on this computer (optional)

    Without this, Update data opens the job on GitHub where you click Run workflow. To run it straight from here, create a fine-grained GitHub token for the AMRJacob/Contours-to-Revit repository with Actions: Read and write permission, and paste it below. It's stored only in this browser.

    Data refreshes automatically every week.

    Add / remove states (GitHub)

    Add a state's name (e.g. oklahoma, new-mexico) on its own line, or delete a line to free the space. Saving rebuilds the data in a few minutes.

    Preliminary only — not survey data. Bare-earth elevations are interpolated under buildings and trees. Elevations: USGS 3DEP, NAVD88.
